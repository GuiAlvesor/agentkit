Escolha um diretório para começar

O AgentKit detecta a linguagem, os comandos e a branch base, e você ajusta o resto aqui.

Os agentes usam exatamente estes comandos. Deixe em branco o que não existir. O deploy é genérico: qualquer comando de shell serve (script, make, docker, kubectl, CLI do provedor).

Hook determinístico

Roda antes de cada comando ou edição, inclusive no Agent SDK. Uma regra por linha (expressões regulares para comandos; globs para caminhos).

Use python ou py no Windows.

Execução fora do Claude Code

Valem para agentkit run, agentkit agent, agentkit review e agentkit release.

GitHub Actions
